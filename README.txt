AI STUDY ASSISTANT Mini Project 10.A - AI-Based Application Development

PROJECT OVERVIEW AI Study Assistant is a web-based learning application
designed to help students understand academic topics and prepare study
materials. Students can enter a subject, education level, study mode,
answer length, and a topic or question. The application uses Gemini AI
to generate student-friendly study content.

PROJECT OBJECTIVE The objective of this project is to provide students
with an easy-to-use AI learning assistant that can explain concepts,
prepare notes, summarize topics, create practice questions, and provide
examples.

LIVE PROJECT AI Study Assistant:
https://bilalvek11-prog.github.io/ai-study-assistant/

GITHUB SOURCE CODE https://github.com/bilalvek11-prog/ai-study-assistant

MAIN FEATURES 1. Gemini API Key: The user enters their own Gemini API
key to connect the application to Gemini AI. 2. Subject Selection: Users
can select Artificial Intelligence, Engineering Physics, Engineering
Mathematics, Basic Electronics, Computer Programming, or Other. 3.
Education Level: Users can select First Year Engineering, Diploma,
School Student, College Student, or Other. 4. Study Modes: - Explain
Topic - Generate Short Notes - Generate Summary - Generate Practice
Questions - Explain With Examples 5. Answer Length: Users can choose
Short and Simple, Medium Detail, or Detailed Explanation. 6. Topic or
Question Input: Users enter the topic or question they want help with.
7. AI-Generated Result: The application displays the study content
generated by Gemini AI.

TECHNOLOGIES USED - HTML: Structure of the web application. - CSS:
Styling, layout, responsive design, and visual appearance. - JavaScript:
Form handling, collecting user selections, creating the prompt, sending
the request, and displaying the result. - Google Gemini API: Generates
educational study content from the user’s input.

HOW THE APPLICATION WORKS 1. Open the AI Study Assistant website. 2.
Enter a Gemini API key. 3. Select a subject and education level. 4.
Select a study mode and answer length. 5. Enter a topic or question. 6.
Click Generate Study Content. 7. The application sends the prompt to the
Gemini API. 8. The generated study result is displayed on the page.

REQUIREMENTS - A modern web browser. - Internet connection. - A valid
Gemini API key. - Access to the Gemini API.

IMPORTANT API KEY SAFETY Each user must provide their own Gemini API
key. Do not share your API key with anyone or publish it in the website
source code, repository, screenshots, or project documentation. Use the
key only in the application’s API key field and follow Google’s API key
safety guidance.

PROJECT OUTCOME The project demonstrates how HTML, CSS, JavaScript, and
a Generative AI API can be combined to build an interactive educational
web application. It provides different study modes so students can
request explanations, notes, summaries, practice questions, and examples
according to their learning needs.

CONCLUSION The AI Study Assistant is a practical example of using
Generative AI in education. It aims to make topic learning and exam
preparation more organized and accessible through a simple web
interface.
